# R&R Sweet Bites

Cake Gallery frontend and PHP/MySQL read backend. The gallery page is in `VS-CODE-R&R`; setup instructions are in [BACKEND-SETUP.md](BACKEND-SETUP.md).

The backend expects the provided MySQL schema (`rr_sweet_bites`) plus the occasion migration in `VS-CODE-R&R/database/add_gallery_occasion.sql`. It uses PHP PDO; local XAMPP defaults and environment-variable overrides are documented in the setup guide.
